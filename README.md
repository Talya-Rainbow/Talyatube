# Talya-Tube

Mobile video share for Talya’s bat mitzvah (English / עברית).

## Run

```bash
python3 server.py
```

Open http://127.0.0.1:8081 (or your PORT).

## Flow
1. Choose language — **English** / **עברית**
2. Bat mitzvah message → **Okay** / **בסדר**
3. App (same videos for both languages)

## Login
Display name only — device is remembered (no password).

## Deploy (Render)
- Start command: `python3 server.py`
- Free web service
